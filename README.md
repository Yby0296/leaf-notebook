# 叶子的小本本 🌿

一个手机端个人工作台 Web App，纯前端、无需后端，数据保存在手机本地（localStorage）。

## 功能模块
- 📚 **学习任务**：大/小论文进度，每日完成率与月度统计
- 🏃 **运动计划**：每日运动打卡
- 🎬 **视频剪辑学习**：精选片段 + 标签 + 学习进度
- 🗣️ **英语口语训练**：每日对话 + 三维评分 + 趋势
- 💰 **我的账户**：存款 + 四类支出 + 周/月/自定义汇总
- 📝 **每日复盘**：心情 + 四模块同步 + 总结
- 📅 **预定计划**：提前预定未来安排，到当天自动提醒并展示

## 使用
手机浏览器打开后，点击「分享 → 添加到主屏幕」即可像 App 一样使用。

## 技术
原生 HTML / CSS / JS，无依赖，托管于 GitHub Pages。
- `index.html` + `styles.css` + `app.js`：开发版本
- `leaf-notebook.html`：单文件离线版（内联全部 CSS/JS，可直接分享）
